# Student-Marks-Calculator

## About the Project
This is a beginner-friendly Python project that calculates a student's total marks, average marks, and pass/fail result.

## Features
- Stores marks using a Python list
- Calculates total marks using `sum()`
- Calculates average marks using `len()`
- Uses `if-else` conditions to determine pass or fail

## Technologies Used
- Python

## Concepts Learned
- Lists
- Variables
- Arithmetic operations
- Built-in functions
- Conditional statements

## Example Output
```text
Student marks: [80, 70, 90]
Total marks: 240
Average marks: 80.0
Result: Pass
```
